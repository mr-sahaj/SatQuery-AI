# Sample-image guidance

To keep this repository lightweight and avoid redistribution issues, no imagery is included. Before the demo, download or use imagery you are permitted to use and test it locally.

Recommended image properties:

- JPG or PNG (the MVP is not a GeoTIFF viewer)
- Clear overhead/aerial scene
- 1024–2048 px on the longest side for a responsive demo
- Distinct features such as water, roads, fields, or large buildings

Keep a local copy of at least two tested examples. Confirm the image licence and attribution requirements before using it in a presentation or repository.
