# 3-minute SIH demo script

1. **Problem (20 seconds):** “Satellite imagery is information-rich, but it is difficult for non-specialists to query quickly.”
2. **Upload (15 seconds):** Upload a prepared aerial or satellite JPG/PNG.
3. **Ask (25 seconds):** Enter a simple visible question such as “Is there a river visible?” and click **Analyze image**.
4. **Explain result (40 seconds):** Show the answer, selected task route, model confidence, and image evidence. Mention that the evidence panel makes the result traceable.
5. **Be precise (25 seconds):** “This MVP uses a general VQA baseline. It demonstrates the interaction loop; the output is indicative, not validated remote-sensing analysis.”
6. **Roadmap (35 seconds):** Point to bi-temporal change detection, Optical + SAR fusion, geospatial grounding, and remote-sensing fine-tuning as future work—not completed features.
7. **Close (20 seconds):** “SatQuery turns an image plus a question into an inspectable answer, creating a strong base for a domain-validated system.”

## Best live-demo questions

- Is there a river or lake visible?
- Are roads visible?
- Are buildings visible?
- What land cover is most prominent?

Avoid fine-grained counts, exact area measurements, or questions that require hidden metadata.
